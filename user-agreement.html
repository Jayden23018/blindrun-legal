一、协议的接受

在使用助盲跑（以下称"本应用"）前，请完整阅读本协议与《隐私政策》。 点击"同意并开始使用"即表示你已阅读、理解并接受本协议全部内容。 如果你不同意其中任何条款，请停止使用本应用。

若你未满 18 周岁，请在监护人陪同下阅读并决定是否使用。

二、本应用是什么，不是什么

2.1 是什么

本应用是一个信息撮合平台，为视障跑者与愿意提供陪跑协助的志愿者提供相互发现和联系的渠道。

2.2 🔴 不是什么

  • 本应用不是陪跑服务的提供者。 实际的陪跑由志愿者本人提供，志愿者不是我们的员工、 雇员或代理人，与我们之间不存在劳动或劳务关系。
  • 本应用不是紧急救援服务。 详见第七条。
  • 本应用不是医疗或健康服务。 我们不提供任何医疗建议、健康评估或运动指导。
  • 本应用不收取任何费用，也不向志愿者支付任何报酬。这是一项公益服务。

三、账号

  1. 你需要用本人的手机号注册，一个手机号对应一个账号。
  2. 你应当妥善保管手机和账号，通过你的账号发出的操作视为你本人的行为。
  3. 你不得将账号转让、出借或与他人共用。
  4. 你可以随时通过【设置 → 删除账户】注销账号。注销后果详见《隐私政策》第六条。
  5. 你在注册和使用中提供的信息应当真实、准确。提供虚假身份信息的，我们有权终止服务。

四、志愿者的额外义务

选择成为志愿者，意味着你额外承诺：

  1. 完成实名认证。这是保障视障用户安全的底线要求，不可豁免。 认证方式可以是【身份证 + 人脸活体】或【身份证二要素 + 人工审核】，两者等效。
  2. 你具备完成陪跑的身体条件，且在服务当时不处于疾病、饮酒、药物影响或过度疲劳状态。
  3. 你已了解视障人士陪跑的基本方法（如引导绳的使用、口头提示的时机与方式）。
  4. 接单后应当按约定到达并完成服务。确需取消的，应当尽早在应用内取消， 让系统有时间重新派单 —— 临时爽约对视障用户造成的困难远大于普通场景。
  5. 服务过程中以受助者的安全为最高优先。遇到路况风险、身体不适或任何异常， 应当立即停止跑步并妥善安置对方。
  6. 不得利用服务过程谋取任何私利，包括但不限于索要财物、推销商品服务、 建立超出服务范围的关系。
  7. 不得记录、传播、公开服务过程中获知的对方个人信息、身体状况或行踪。

五、视障用户的义务

  1. 如实说明你的视力状况与身体状况中影响同行安全的部分。
  2. 如实填写起点、终点和期望时间。
  3. 服务过程中听从志愿者关于安全的合理提示。
  4. 尊重志愿者，不提出超出陪跑范围的要求。
  5. 妥善填写紧急联系人，并事先告知对方你填写了其号码。

六、双方共同的行为规范

禁止以下行为，一经发现我们有权立即终止服务并封禁账号：

  • 骚扰、歧视、辱骂、威胁对方，或做出任何令对方不适的言行
  • 提供虚假身份信息，或冒用他人身份
  • 滥用紧急求助功能（虚假求助会挤占真实求助的响应资源）
  • 利用本应用从事任何违法活动
  • 以任何方式干扰、破坏本应用的正常运行
  • 未经对方同意，记录、传播或公开对方的个人信息、影像或行踪

七、🔴 紧急求助功能的性质与限制

本应用的"紧急求助"功能不是紧急救援服务，不能替代 120、110 或任何官方急救渠道。

它的全部作用是：向你事先自行填写的紧急联系人发送一条短信，并通知平台客服人工跟进。

它可能失效，原因包括但不限于：手机没有信号、手机没电、短信通道故障、 紧急联系人没有查看手机、紧急联系人号码填写有误。 我们不保证送达，也不保证有人响应。

遇到紧急情况，请首先拨打 120（急救）或 110（报警）。 本应用界面中提供了直接拨打的入口。

  2. 本应用对志愿者的审核限于身份真实性（实名与活体认证）， 我们不对志愿者的陪跑技能、身体素质、性格品行或服务质量作任何保证。

  3. 对于用户之间在服务过程中发生的纠纷、损害或争议， 由当事人依法自行解决。我们会在合理范围内提供我们所掌握的订单与轨迹记录，协助查明事实。
